# Rezoni Store - Pixel-Perfect E-Commerce UI Clone

A 100% faithful, pixel-perfect clone of [Rezoni](https://www.rezoni.com) built using modern web technologies: Next.js 15 (App Router), TypeScript, and CSS matching Shopify's Focal theme.

## 🚀 Features

- **Hero Image Slider**: Interactive desktop and mobile responsive carousel with live assets, swipe support, and thin white chevrons matching the live store.
- **Header & Navigation**:
  - Rotating Sticky Announcement Bar with live promotional messages.
  - Sticky black header with Kwikpass lightning badge icon, real-time cart bubble, and search modal.
  - Multi-column Mega Menu for "Shop By Category" (Cases & Protection, Accessories, Collections) and "Shop By Device" (Apple, Samsung, OnePlus, Google Pixel, etc.).
  - Mobile slide-out drawer menu with accordion accordions.
- **Product Presentation**:
  - Horizontal snap-scroll collection carousels with stacked navigation buttons ("Anti-Yellow Case", "Reverb 2.0 Case", "Featured Collections", "Personalise Your Case").
  - Responsive product grid for "Best Sellers" and "New Arrivals" featuring live product titles, subcategories, sale prices, compare-at pricing, and concentric 5-color swatches.
  - Image swap on hover and interactive Quick Add.
- **Product Detail Page (PDP)**:
  - Interactive multi-image gallery with thumbnail switcher and zoom button.
  - Snapmint 0% EMI preview widget.
  - Summer Sale & 3 Free Gifts promotional banners.
  - Model dropdown selector for all iPhone models.
  - Live 6-digit Pincode & COD availability checker.
  - 3 Trust Badges (Express Delivery, 7 Day Risk Free, Secure Payments) + 100% Money Back Guarantee seal.
  - "As Seen On" media carousel + Description & Shipping tabs.
  - Sticky bottom Add to Cart bar on scroll.
- **Cart Drawer (Mini Cart)**:
  - Slide-in side drawer with live subtotal calculation.
  - Green trust banner ("Trusted by 10,00,000+ customers!").
  - Dynamic Free Shipping progress meter.
  - Quantity increment/decrement, remove items, and GoKwik 1-click checkout.
- **Footer**:
  - Information and Shop brand directory.
  - Boxed social media links (Facebook, Instagram, Pinterest).
  - Customer support contact line.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: CSS & Design Tokens (Shopify Focal theme matching)
- **Icons**: Lucide Icons & Custom SVG sprites
- **Deployment**: Vercel

## 📦 Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Visit [http://localhost:3005](http://localhost:3005) to view the application.

### Production Build

```bash
npm run build
npm run start
```
